# Public / Proprietary Boundary

This repository discloses theories, equations, test designs, public-safe algorithms, simulation summaries, application concepts, maturity labels, failures, and provenance.

It does not publish:

- credentials, tokens, personal records, or private communications;
- protected material from the Drive folder named “Gpt Not Allowed to alter”;
- private code or architecture from “DT Value Platform - PRIVATE”;
- operational offensive cyber instructions;
- real exploit payloads, credential traps, target data, or unauthorized-access procedures;
- unpublished third-party material;
- reconstructed prose falsely labeled as verbatim source.

Prism security may be described as a bounded defensive simulation architecture: synthetic canaries, false-success conditions, footprint observation, containment, rollback, and branch preservation. Public disclosure must not convert that research into an attack playbook.

Public visibility grants no additional reuse license. A separate license decision is required before any material is treated as open source.
