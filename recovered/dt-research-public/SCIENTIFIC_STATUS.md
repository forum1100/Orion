# Scientific Status

DT uses explicit maturity labels so disclosure does not become false validation.

| Label | Meaning |
|---|---|
| Operational method | A usable workflow; not proof of a scientific theory |
| Executed synthetic test | Code ran on constructed data under recorded conditions |
| Historical run claim | A prior record reports a result; execution evidence still requires recovery |
| Theoretical/testable | Variables and a prospective test can be specified |
| Speculative/incomplete | Formalization, units, observations, or validation remain missing |
| Failed/rejected | The branch did not survive; retained for history and learning |
| Provenance unresolved | Exact source, chronology, or authorship boundary is incomplete |

DT is not validated physics, mathematically closed, or empirically proven. Simulation output cannot by itself prove DT true. Claims must remain attached to sources, assumptions, rivals, predictions, observations, residuals, and authority.

## Nonclaims

This repository does not establish reactionless propulsion, perfect cloaking, local faster-than-light motion, accessibility curvature as gravity, AI consciousness, inevitable civilization outcomes, or universal explanatory superiority.
