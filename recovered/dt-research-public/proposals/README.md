# Research Proposals

## Minimum viable testing rules

1. Freeze the claim, prediction, baseline, parameters, and failure rule before execution.
2. Compare the closest ordinary or established rival.
3. Test a branch alone, paired, in a triad, and with a necessary neighbor absent.
4. Preserve nulls, failures, contradictions, timeouts, and adjacent damage.
5. Separate synthetic execution from external validation.
6. Reopen only when new evidence changes selectability.

## Priority proposals

- Operationalize accessible-state counting across bounded domains.
- Perform dimensional audits for every physics-facing equation.
- Test persistence thresholds out of sample against simpler memory/coherence models.
- Compare distributed stewardship, centralized correction, and optimization pressure across preregistered civilization scenarios.
- Test whether branch-interaction terms predict outcomes beyond additive baselines.
- Evaluate hallucination signals using source-grounded blinded corpora.
- Test defensive Prism canaries in isolated authorized environments against matched benign controls.
- Recover and rerun historical code before relying on numerical claims.
- Measure capability gained versus dependency introduced by AI assistance.
- Develop visual learning studies comparing equations, causal maps, narratives, and interactive workbenches.

The strongest proposal is always the smallest test capable of discriminating DT from a simpler explanation.
