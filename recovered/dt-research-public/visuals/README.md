# Visual Index

GitHub-rendered Mermaid diagrams are used for exact conceptual topology. Future illustrated guides should draw from Thomas Cutler's memoir, reflections, family explanations, and creative writing without exposing private people or records.

## DT causal spine

```mermaid
flowchart TD
 I[Interaction] --> C[Constraint]
 C --> S[State]
 S --> R[Persistent structure]
 R --> P[Perspective]
 P --> D[Distinguishability]
 D --> A[Agency candidate]
 A --> F[Observable footprint]
 F --> X[Residual]
 X --> I
```

## Recursive testing loop

```mermaid
flowchart TD
 P[Freeze prediction] --> E[Execute]
 E --> O[Record observation]
 O --> R[Preserve residual]
 R --> B[Pair triad and absence tests]
 B --> N[Smallest next correction]
 N --> P
```

Visuals explain relationships; they do not increase a claim's evidentiary status.
