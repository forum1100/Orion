# Execution Evidence Register

Running code establishes software behavior under recorded inputs. It does not by itself establish physical, biological, social, or cosmological truth.

| Class | Minimum evidence | Permitted claim |
|---|---|---|
| Proposed | Description only | Test has been proposed |
| Reconstructed | New code based on historical description | A reconstruction exists |
| Executed synthetic | Code, environment, input, seed, and output | Synthetic behavior was observed |
| Reproduced historical | Source-faithful artifact and matching output | Historical computation was reproduced |
| External-data test | Licensed dataset and preregistered analysis | Dataset result was observed |
| Independently replicated | Independent implementation or laboratory | Result replicated within stated scope |
