# Orion

**Orion is a free AI desktop platform provided by Distel Axiom Dynamics.**

Orion is developed in public. **No purchase, subscription, or commercial-use royalty is required to use Orion.** Donations are entirely voluntary. Not donating does not reduce anyone's right to use an authorized Orion release.

## Support and updates

- Developer's personal X profile: [@thomasdistel](https://x.com/thomasdistel)
- Voluntary contributions: see the donation/payment-card information the developer shares directly on X. No card details, payment credentials, or unverified payment URLs are distributed in this repository.

## Public development, private personal data

Orion's engineering, source code, design, simulations, evaluation methods, and research can be published openly. **Personal and family records, confidential third-party material, credentials, tokens, private correspondence, and payment-card information must not be published without appropriate authorization.** A public GitHub repository cannot provide per-file private access: protected material remains in separately access-controlled storage.

## GitHub + Google Drive

During development, GitHub is a public source/version-control and review channel **alongside** Google Drive, not a replacement for it. Google Drive remains the durable archive for Memory Convergence, Perception Points, source provenance, experiment records, checkpoints, and recovery. Orion's local runtime and Guardian are not dependent on GitHub availability. See [Development and disconnection policy](DEVELOPMENT_AND_DISCONNECT.md).

## Project status and licensing

Orion is in active development, not presented as a finished or independently certified AI security product. The detailed copyright license governing modification, redistribution, and derivative distribution is still to be selected; publishing the source and making Orion free to use does not by itself settle every reuse right. Donations are optional, not a licensing fee.
