## Interpretation priorities
1. Owner's most recent explicit requirement controls **intended direction**, not what is actually deployed.
2. The source as written controls what an earlier model or actor actually said; older text must not be silently edited to match new authority decisions.
3. A live system observation overrides historical assertions about *current runtime status* only, and must be dated.
4. Provider agreement or duplicate Drive copies do not count as independent corroboration.
5. The October 13 archive explicitly warns that the full original clipboard transcript and underlying Gmail link bodies were not all independently verified. This repository does not claim complete verbatim recovery of those gaps.

**Current change:** on October 18 the owner reauthorized **both** Google Drive and public GitHub development, reserving the right to sever the GitHub integration after development. Old GitHub-retirement patches remain as true historical events.
