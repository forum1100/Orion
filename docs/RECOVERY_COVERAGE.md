## Exact-copy and release distinction

- The 184 research files are drawn from an **already public** research repository and include its source ledgers, replay packs, equations, test scripts, branch failures, data and original status labels.
- The 349 Orion checkpoint files were screened for credential signatures, email addresses, private users/mount paths, unreviewed binaries, and runtime/configuration data. This is a conservative **automated** screen, not a professional manual security audit.
- **110 historical Orion files are intentionally held** for explicit review: missing files in this mirror are listed with paths, hashes, reason and source commit in the manifest.
- The Google recovery originals remain in owner-controlled Drive custody. Publication of a newly derived explanation is not the same as publishing all raw owner-private transcripts.
- Having source code visible is not evidence the program is currently running, and a stored run receipt is not proof of a novel physics result.
