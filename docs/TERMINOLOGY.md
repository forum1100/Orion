# Living Orion / DT / cross-provider dictionary

**Read before changing code.** This crosswalk contains Orion project usage and selected descriptions found in Google AI historical work. It does **not** claim that Gemini, Grok, or OpenAI internally use identical terms. If a provider uses a term differently, record the context and source; do not quietly redefine it.

## Owner's working style (non-sensitive collaboration preferences)
Start from the **big picture**, then decompose. Seek long-lived context instead of repeatedly asking for the same authorization when a valid scoped standing grant exists. Make the system proactively keep its own tasks moving. Explain both `what` and `why`, not only jargon. Track where a claim originated (ChatGPT, Gemini, Grok, user, run, file) and never pretend external-provider text is the owner's personal statement.

## Updating this dictionary
New words require: term, plain-language definition, technical definition, first known original source/date, alternative names by provider, incompatible meanings, confidence, and a reviewable contribution record. A proposed interpretation remains provisional until checked against the originating material and owner decisions.
